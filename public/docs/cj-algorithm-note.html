CCTV 기반 박스 수량·크기 추정

카메라 정보가 없는 CCTV 영상만으로 벨트 위 모든 상자의 개수와 가로·세로·높이(cm)를 추정한다.

10.471공식 채점 (낮을수록 좋음)
50개 영상총 435개 박스 분석
약 12초영상당 추론 · GPU 실측

상자는 카메라에서 멀어질수록 작게 보이고, 실제 폭이 62.3cm인 레일은 모든 위치에서 함께 관찰된다. 이 두 가지 관찰이 알고리즘의 핵심이다.

핵심

세 가지 아이디어

IDEA 1

레일이 기준자가 된다

실제 폭이 62.3cm인 레일은 화면의 모든 위치에서 관찰된다. 위치별 레일의 픽셀 폭을 측정하면 1cm가 몇 픽셀에 해당하는지 계산할 수 있다.

IDEA 2

상자마다 특징을 요약한다

실루엣, 접근 패턴, 꼭짓점 8개를 결합해 상자 하나를 27개의 수치로 요약한다.

IDEA 3

회귀로 교정

직접 측정한 값의 체계적 오차를 회귀 앙상블로 보정해 최종 (w, d, h)를 산출한다.

흐름

일곱 단계

두 개의 신경망이 시각 인식을 담당하고, cm 환산과 최종 판단은 기하 계산과 회귀 모델이 담당한다. 크기 추정 경로와 개수 추정 경로는 독립적으로 진행되다가 ⑦ 단계에서 결합된다.

STEP 1

상자와 레일을 검출한다

프레임마다 상자와 레일의 위치를 픽셀 단위 윤곽으로 검출한다.

직접 라벨링해 학습한 segmentation 신경망(YOLO11l-seg)이 box와 rail 두 클래스의 윤곽을 검출한다. 개수 추정에는 5프레임 간격을, 크기 추정에는 10프레임 간격을 사용한다.

STEP 2

레일 폭을 기준으로 픽셀을 cm로 환산한다

화면 전 구간에서 관찰되는 레일의 실제 폭 62.3cm를 유일한 길이 기준으로 사용한다.

그 위치의 환산율 = 레일 픽셀폭 ÷ 62.3cm 상자 변 cm = 픽셀길이 ÷ 환산율(상자 위치)

레일의 좌우 경계를 직선으로 근사하면 화면 어느 위치에서든 레일의 픽셀 폭을 cm 환산율로 변환할 수 있다. 멀리 있는 상자와 레일은 함께 좁아 보이므로 원근 효과가 자동으로 반영된다. 따라서 별도의 카메라 캘리브레이션이 필요하지 않다.

STEP 3

프레임 사이에서 동일한 상자를 추적한다

수십 프레임에 흩어진 관측 결과를 동일한 상자의 이력(트랙)으로 연결한다.

추적이 끊기면 하나의 상자가 여러 트랙으로 분리되어 크기와 개수 추정이 모두 왜곡된다. 이를 줄이기 위해 예측-겹침 매칭에 레일 방향 기반 대체 경로를 추가했다.

STEP 4

완성된 트랙으로 상자 개수를 집계한다

개수는 프레임별 검출 수를 단순 합산하지 않고 영상 전체 통계로 회귀한다. 한 장면만으로는 겹침과 가림 때문에 정확한 개수를 판단하기 어렵다.

영상 전체를 요약한 31개 통계(검출 시계열 21 + 원거리 2× 줌 재검출 5 + 역방향 추적 5)를 사용해 개수 N을 회귀한다. 마지막 단계에서는 이 N을 최종 출력 개수로 사용한다.

STEP 5

상자의 가로·세로·높이를 추정한다

실루엣 13 + 접근 패턴 4 + 꼭짓점 7 + 파생 특징 3 = 27차원 특징 벡터.

실루엣 (13)

가장 선명한 7개 프레임의 윤곽에서 폭·높이·면적·비율을 cm로 환산한 뒤 중앙값을 집계한다. 이 값이 특징 벡터의 기본 골격이 된다.

접근 패턴 (4)

꼭짓점 8개 (7)

두 번째 신경망(YOLO11l-pose)이 직육면체의 꼭짓점 8개를 검출한다. 꼭짓점 좌표를 이용하면 W·D·H 각 방향의 변 길이를 4개씩 계산할 수 있다.

양 끝점이 명확한 변만 선택해 픽셀 길이를 레일 기준으로 cm로 환산한다. 가려진 꼭짓점을 포함한 변은 제외하고, 바닥 가림으로 높이를 직접 측정할 수 없을 때는 윗면 꼭짓점과 실루엣 바닥선 사이의 간격을 사용한다.

방향 보정 — D는 눌려 보인다

마지막으로 W와 D의 순서가 바뀌는 경우에 대비해 파생 특징 3개(max·min·비율)를 추가하고 27차원 특징 벡터를 완성한다.

STEP 6

회귀 모델로 측정 오차를 보정한다

27차원 특징 벡터는 1차 측정값이며, 학습된 회귀 모델이 가림과 원근에서 발생하는 체계적 오차를 보정한다.

(w,d,h) 직접 대신 → [ 크기 = (w·d·h)^⅓ , 모양비 2개 ]를 예측 후 복원 크기는 실루엣·레일이, 모양은 꼭짓점·다가옴이 잘 안다 — 분리해서 배운다

오차 특성이 다른 두 계열을 50:50으로 결합한다. 첫 번째는 선형+트리(이상치에 강한 Huber 선형 모델 + GradientBoosting 잔차 모델 5-seed), 두 번째는 신경망(TabM 3-seed)이다. 또한 측정 설정(꼭짓점 채택 엄격/관대 × 트랙 평활 강/약)을 2×2로 구성해 특징 세트 4개와 전용 헤드 4개의 결과를 평균한다.

STEP 7

최종 결과 파일을 생성한다

예측한 개수 N과 크기 측정에 성공한 트랙 수 M을 결합해 최종 출력을 결정한다.

중간 경로의 대체값은 같은 영상에서 측정에 성공한 상자 크기의 중앙값이다. 이 값은 영상마다 다르며 해당 영상을 분석한 뒤에만 계산된다. 예외 처리는 프레임 단위와 영상 단위로 이중 격리해 일부 단계가 실패하더라도 유효한 result.json을 생성한다.

추론

실행 순서 — 영상 하나가 결과가 되기까지

python main.py --input 폴더 명령 한 줄로 다음 전 과정을 실행한다. 추론 시에는 학습을 수행하지 않고 사전에 준비한 모델만 불러와 사용한다.

  • 모델은 전부 ONNX — 추론에 학습 프레임워크가 필요하지 않으며 numpy·cv2·onnxruntime만으로 동작한다.
  • 결정론적 추론 — 같은 영상을 입력하면 항상 같은 결과를 반환하며 무작위성이 없다.
  • 부분 실패 시 대체 경로 — 꼭짓점 모델을 사용할 수 없으면 실루엣만으로, 개수 모델을 사용할 수 없으면 프레임 통계로, 레일 검출이 끊기면 보조 근사값으로 처리해 어떤 상황에서도 유효한 출력을 생성한다.
채점

채점 방식이 설계를 결정했다

점수는 부피 순위가 같은 상자끼리 매칭한 뒤 세 변의 차이를 합산한다. 따라서 개수 오차의 영향이 크다.

상자를 하나 초과하거나 누락하면 세 변 합 전체(수십 cm)가 그대로 페널티로 반영되어 크기를 몇 cm 개선한 효과를 한 번에 상쇄한다. 그래서 개수 전용 회귀 모델을 두고, 탐지 수가 아니라 N으로 최종 출력 개수를 결정한다. 부족한 슬롯은 0이 아니라 해당 영상에서 측정한 크기의 중앙값으로 채운다.

학습

모델 학습 과정 — 상세

학습은 제출 전에 모두 완료한다. 두 신경망은 직접 구축한 라벨로, 회귀 모델은 학습 영상의 정답 크기로 학습한 뒤 ONNX 형식으로 저장한다.

1 · 두 신경망 — 픽셀 라벨을 직접 구축했다

대회가 준 것은 영상과 "영상별 상자 크기 목록"뿐, 픽셀 라벨은 없다. 그래서 학습 영상 프레임에 상자·레일 윤곽과 꼭짓점 8개를 직접 라벨링했다.

모델라벨학습 과정
검출 (상자·레일)프레임별 윤곽 폴리곤 — 자동 사전 라벨링 후 수동 보정YOLO11l-seg 학습 → 놓친 프레임을 영상 검수로 찾아 학습셋에 추가 → 재학습 → ONNX 변환
꼭짓점 8개상자마다 직육면체 꼭짓점 8점 (가려진 점 포함)YOLO11l-pose 학습 → ONNX 변환 (원본 가중치 동봉, 재현 가능)

2 · 회귀 학습쌍 — 부피 순위로 매칭

라벨은 "이 영상에 이런 크기들이 있다"는 목록일 뿐, 어느 트랙이 어느 상자에 해당하는지는 제공하지 않는다. 따라서 채점과 동일한 기준으로 매칭한다.

3 · 무엇을 배우나 — 크기와 모양을 분리

타깃: (w,d,h) 그대로가 아니라 → [ 크기 = (w·d·h)^⅓ , 모양비 2개 ] 크기 오차와 모양 오차가 한 손실에 섞이지 않게 분리 → 예측 후 (w,d,h)로 복원
구성요소내용선택 이유
계열 A — 선형+트리이상치에 강한 선형 적합(Huber) + 잔차를 GradientBoosting 5-seed가 흡수안정적인 선형 기준선 + 비선형 잔차 보정
계열 B — 신경망경량 tabular 신경망(TabM) 3-seed, 결정론적 학습계열 A와 오차 패턴이 달라 50:50 블렌드로 서로의 오차를 보완
측정변형 4-head측정 설정 2×2(꼭짓점 채택 엄격/관대 × 트랙 평활 강/약)마다 전용 헤드한 측정 설정의 약점을 다른 설정이 보완
개수 회귀31-dim 통계 → Ridge개수는 크기 추정과 독립된 경로로 처리

4 · 신뢰성을 높이는 두 가지 장치

# 학습 스크립트 (train_src/retrain_size.py) import main as M # ← 추론 파일을 그대로 import feats = M._track_feature(...) # 지문 계산 함수 공유 Y.append(M._shapevol_encode(gt)) # 타깃 인코딩도 공유
  • 동일한 계산 로직 공유 — 학습 스크립트가 추론 코드의 함수를 그대로 사용한다. 따라서 학습과 추론에서 특징 계산 방식이 달라져 발생하는 성능 저하를 구조적으로 방지한다.
  • 영상 단위 교차검증 — 같은 영상의 상자가 학습과 검증 데이터에 나뉘지 않도록 영상 단위로 분리해 평가했다. 개선 효과가 불분명할 때는 시드를 바꿔 반복 검증했으며 테스트 정보는 어떤 형태로도 사용하지 않았다.
